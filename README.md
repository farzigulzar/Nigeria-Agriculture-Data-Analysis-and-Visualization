# Nigeria-Agriculture
\begin{itemize}
\item Analyzed 1,000 agricultural export transactions spanning 2020–2023, aggregating 536K+ units and \$16.32B in export value across products, firms, countries and ports.
\item Identified key revenue drivers, with Cocoa generating \$2.38B (14.6$\%$) of export value and Italy emerging as the largest destination at \$1.96B.
\item Uncovered temporal patterns, including a 27.3$\%$ Q4 share of annual export value and YoY export-value changes of +14.7$\%$ (2021), $-$15.4$\%$ (2022), and +10.9$\%$ (2023).
\item Mapped export concentration, finding Lagos responsible for 59.7$\%$ (\$9.74B) of total export value and the top 5 exporters contributing 53.1$\%$, highlighting significant company and logistics concentration
\end{itemize}
